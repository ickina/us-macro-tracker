# マーケット変更の確認記録

2026-11-12 JST。ユーザーによる実装・確認・公開の承認範囲。

## 今回の変更

- TradingViewの帯と詳細でドル円・ユーロドル・BTC・ETH・NVDA・金の同一シンボルを使用。残る8銘柄は既存保存グラフ。
- 14銘柄の共通選択は名称のみ。鮮度・日次データ日・NVDA15分遅延・比較期間は詳細で案内。
- スマホにも公式regularモードの1段価格帯。実測iframe高60px、別途帰属と日次騰落の説明行。公式内容・ロゴを切り取らない。帯からアプリ内詳細の連動は付けない。
- 詳細は初期1Y。既存4銘柄の保存履歴と従来期間へもアクセス可能。
- グラフへ残り高を配分。公式詳細は最低280pxを確保し、320×640など短い画面では詳細枠のみ縦スクロール。過度に縮めると公式ロゴが期間ボタンへ重なることを実試験で発見し、回避した。
- スケジュールは文字付きの横並びボタン。予約領域48px＋端末安全領域に縮小。全3ページで本文との重複を回避。
- ダッシュボード41項目・取得系列・計算・保存データ・ニュースを維持。将来の移動は未決定。表示名の問題はdata-label-review.mdへ記録のみ。
