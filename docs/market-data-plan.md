# マーケット一覧と追加銘柄の準備状況

## 実装済みの表示

- 下から開く一覧は既存の12系列を再利用し、初回に開くまで価格データを取得しない。
- 専用の静的 `/api/markets` は必要な系列だけを返す。5分間は取得済みデータを利用し、手動の再取得も可能。
- 表示は日次の保存データ。再取得ボタンは保存データを読み直すもので、リアルタイム価格への更新ではない。
- 左右スワイプ、マーケットに該当するお気に入りの抽出、詳細グラフへの移動を実装。
- FRED＋為替補完の値を、そのままFRED単独の値と表記しない。
