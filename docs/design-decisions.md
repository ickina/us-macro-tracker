# ichiの米国経済指標：設計の前提と相談状況

最終整理：2026-11-11。前チャットの引き継ぎ、現行コード、Git履歴、このチャットでのユーザー発言を照合した記録。
新しい作業では本書と実画面を確認する。相談案を承認済みの仕様として実装しない。

## 目的と維持する前提

新規アプリとして設計し直す依頼ではない。既存の読みやすさ・使い勝手を土台に、相場を見る機能を充実させる。
正式名称は「ichiの米国経済指標」。勝手に「ichi」だけへ短縮しない。
見出しは「米経済指標 ダッシュボード」「米国マクロ経済ニュース ＆ リリース情報」。
ライトが初期表示で、選択したテーマは `macro-theme` で保持する。
お気に入り、NEW表示、長期履歴、期間切替、ニュース検索、共有画像、ホーム画面アイコンを維持する。
タイトルを単に小さくすることを既定の解決策にしない。

## 現在の画面

- 上部ナビは「ダッシュボード／マクロニュース」。PCではヘッダー右側、スマホではタイトル下。
- ダッシュボードは見出し・更新ボタン・今日の注目帯・カテゴリ・指標カード。
- ニュースにも今日の注目帯があり、検索はアイコンから開く。
- 左下の「マーケット」から下部シートを開き、手動で横に動かすカードと詳細グラフを使う。
- 右下は文字付きの青い「スケジュール」ボタン。重要な機能であり、この表示はユーザーが気に入っている。削除や「予定」への改名は未決定。
- 注目帯はすでに実装済み。大きなパネルで本文を下に押し出さないため、全幅の細い帯にした。一時停止・動きを減らす設定・予定一覧への連携がある。
- 注目帯は既存の予定生成処理を使う。公式の予定を常時リアルタイム取得していると説明しない。

## 銘柄と帯の重要な意図

帯と本体の銘柄をできるだけそろえる。既存BTC・ETH等との重複は問題ではなく、重複だけを理由に帯から削除しない。
帯にある銘柄をアプリ内でも詳しく見られる方向を目指す。差がある場合は明示する。
ただし現在の試験行は公式Ticker Tapeではなく、Symbol Overviewカード。ティッカー帯の完成コードは未受領で、アプリ内グラフへのクリック連動も未確認。
NASDAQ総合とNASDAQ-100、金とPHLX XAU、現物指数と指数CFDを同一扱いしない。
金はCMC Marketsの「Gold - Cash」でありCMEではない。

前チャットでユーザーが確認：ICEのNYFANGはティッカーテープに「This symbol is only available on TradingView」と表示された。検索に出ることは埋め込み可能の証明にならない。有料契約で解決するとは確認していない。
他銘柄・他ウィジェット・利用条件は個別に確認する。無料APIや個人の有料契約だけで再配信権があるとは説明しない。

## 相談中：実装承認はまだない

- マーケットを上部の第3タブにし「ダッシュボード／マーケット／マクロニュース」とする案。
- 左下のマーケット入口を上部へ移す案。
- マーケット内は手動の銘柄選択と大きな1銘柄グラフにする案。
- 自動ティッカーを概況用に併用する案。ユーザーは自動・手動双方に関心がある。
- マーケットにも既存の今日の注目帯を表示する案。
- 右下スケジュールを維持し、操作との重なりを防ぐ案。
- 為替・株価指数・BTC/ETH・商品等をTradingViewへ集約する案。

既存カードの削除、取得停止、3タブ化、名称変更、注目帯へのニュース追加、CPI/PPI等のTradingView移行は決定事項ではない。
スケジュールが重要であること、マーケットの現在の入口は存在感が弱いこと、マクロニュースを維持したいことはユーザーの明示的な希望。
大きな変更の前に、現在のPC・スマホ画面に即した具体的な変更イメージを示す。文字だけの一般的な配置図で判断を求めない。
