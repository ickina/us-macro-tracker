# マーケットUI案（設計のみ）

2026-11-12 JST追記：大枠と下記修正をユーザーが採用し、実装・確認・公開を承認。古い案を含む本文より、この追記とdesign-decisions.mdの最新承認を優先する。

- スマホ価格帯は細い1段で常時表示する案を第一候補として検証。初期折り畳みは採用しない。
- 銘柄ボタンは名称のみ。相場／日次履歴ラベルを付けない。鮮度・データ日は詳細へ。
- スケジュールの予約領域は最小限。既存41項目を維持し、将来の移動案は未決定。

## 構成

既存ヘッダーと3ナビ、テーマを維持。マーケットでは今日の注目帯を表示しない。
公式価格帯は鮮度改善4銘柄と追加2銘柄の6つだけ。同一シンボルを詳細にも使用。帯から詳細への連動は未確認のため付けない。保存値の帯は使わない。
PCは帯→1行の手動選択→大きな詳細。スマホはグラフ優先で帯を折り畳み可能とし、初期は閉じる案。帯の新規読込は表示時に限る。折り畳み方式は未実装。
共通選択は14銘柄を同じボタンで並べ、取得方式ごとに選択UIを分けない。スマホは1行横スワイプ、PCは横スクロールと左右ボタン。価格は載せず銘柄名と「相場」「日次履歴」の小ラベルにし、価格重複・更新時差を避ける。選択色は既存青を維持。
順序案：ドル円、ユーロドル、S&P500、NASDAQ総合、NYダウ、日経平均、BTC、ETH、金、NVDA、WTI、天然ガス、VIX、金銀鉱山株。選択中を可視範囲へ移す。お気に入りは選択欄を増段せず見出し横に維持。

## 共通詳細枠

外枠・余白・背景・角丸をそろえる。共通見出しは銘柄名と情報種別だけ、価格・変化率をアプリ側へ複製しない。TradingView内のヘッダーは残るため名称の再表示は制約として許容し、アプリ見出しを小さくする。
相場6銘柄は公式Symbol Overviewをそのまま表示。初期1Y、内部期間ボタン、提供元・遅延・帰属を維持。外部共通期間ボタンで操作できるとは約束しない。既存8銘柄は既存価格・前回比・期間ボタン・グラフを維持。全14銘柄で初期1Y。
統一対象は外側の枠と情報の説明。内部レイアウトや期間選択肢は無理にそろえない。TVは選択期間の騰落、既存は前回観測値比、帯は日次騰落と明記する。
データ日・高安値・取得元などは既存詳細の折り畳みに残す。日次価格の日付は閉じた状態でも見せる。TVの鮮度は独自時刻を作らず公式表示を尊重。NVDA15分遅延を枠外でも表示する。
相場へ変更する既存4銘柄では「保存履歴」を詳細下の補助入口として設け、従来の1Y/3Y/5Y/10Y/ALLへアクセス可能にする案。公式の期間選択を失わせる置換はしない。
スケジュールは文字付きで全ページ維持。共通フッター領域に置き、操作と重ねない。スマホは選択欄を固定多段にせず、補助情報を閉じた初期状態でプロットが見える高さを優先する。極端な低い画面では詳細領域のスクロールを許可。

## ダッシュボードとの重複

今回は41項目を削除・非表示にしない。保存履歴と経済指標の比較という役割を維持。
【未決定の参考案】将来の移動候補はBTC・ETHとS&P500・NASDAQ総合・NYダウ・日経平均。前者は相場確認の主用途、後者は市場指数群としてマーケットへまとまりがあるため。ただし相場4銘柄と異なり後者の鮮度は変わらず、移動は情報改善ではなく整理である。
ドル円・ユーロドルは金利との比較、VIXはリスク環境、WTI・天然ガスはインフレ、金銀鉱山株は金価格との違いと株式感応度の観察のため当面残す推奨。
金・NVDAはマーケットのみ。41項目へ自動追加しない。移動候補も実行は別途判断し、お気に入り・長期履歴・既存の入口を先に失わせない。

## 次段階の確認条件

PCとスマホの両テーマ、短い画面、14選択、初期1Y、従来履歴、帯開閉、スケジュール非重複を確認する。TV内部を既存グラフと同じにできたとは表現しない。公式埋め込みが読めない場合はエラーと再試行を示し、古い保存値へ無表示で代替しない。
