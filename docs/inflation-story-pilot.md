# インフレ3指標と利下げ材料の読み解き（ローカル検証）

確認基準日：2026-11-15 JST。使用するのは既存の `CPIAUCSL`・`CPILFESL`・`PCEPILFE` の保存データで、追加通信や取得系列の変更は行わない。各系列は既存取得処理で前年同月比へ加工済み。

## 判定方針

- CPI・コアCPI・コアPCEの最新値と前月値を比較する。
- 3つが低下または横ばいで、少なくとも1つが低下なら `物価は落ち着く方向`。
- 3つが上昇または横ばいで、少なくとも1つが上昇なら `物価に再加速の気配`。
- 上昇と低下が混在する場合は `物価の動きはまちまち`。多数決にしない。
- 対象月ずれ、75日を超える鮮度、未来日付、欠損、履歴不足では `材料待ち`。
- CPIとPCEの手法差を無視して同じ数字とは扱わない。3系列が同じ方向かを見る。

## 利下げへの材料

雇用と物価の定型判定を組み合わせる。市場が実際に織り込む利下げ確率ではなく、経済指標から見た材料だけを示す。

| 雇用 | 物価 | 表示 |
| --- | --- | --- |
| 弱い方向 | 落ち着く方向 | 追い風 |
| 強い方向 | 強まる方向 | 逆風 |
| 上記以外の有効な組合せ | 各方向をそのまま説明 | 綱引き |
| どちらかが保留 | 判断を出さない | 材料待ち |

常に「市場の最新の織り込みは、金利先物などで確認してください」と案内し、利下げ時期・確率・株価・売買を断定しない。

## 実データの生成例

- CPI（2026年9月）：3.72％、前月から0.37ポイント上昇。
- コアCPI（2026年9月）：2.57％、前月から0.12ポイント上昇。
- コアPCE（2026年9月）：3.12％、前月から0.09ポイント上昇。
- インフレ判定：`物価に再加速の気配`。
- 雇用判定：`強さの中に、少し揺れ`。
- 利下げへの材料：`綱引き`。物価は強まる方向だが、雇用は強い面と弱い面が混在しており、一方向にそろっていない。
