# 試用中の表示機能を戻すための記録

画面の表示機能だけを個別に取り消し、指標データ・自動取得・お気に入りは維持する。
自動取得のコミットを失わないよう、履歴を巻き戻す reset や force push は使わず、対象差分の取り消しを新しいコミットにする。

## ② 今日の注目

- 追加コミット：`2901a3c`。
- ダッシュボードからニュースへ移動したコミット：`0044384`。
- コンパクト版ではダッシュボード・ニュース両方の `TodayHighlights` から表示。高さ約56pxの帯に1件だけ表示し、同日のほかの予定は件数とカレンダーで案内する。
- 機能をなくす場合は、両ページの `TodayHighlights` の呼び出し・importを外す。必要なら関連コンポーネントとカレンダー連携だけ取り除く。③のNEW表示やお気に入りは残す。
- 移動だけを取り消す場合はニュースからダッシュボードに戻るため、「機能を削除」と区別する。

## ③ 前回表示からの更新目印（NEW）

- `feat: mark indicators updated since previous visit` のコミットとして②と分離する。
- カードのNEW表示、`useIndicatorUpdates` と `indicatorUpdates` が対象。
- ローカルの目印：`backup/before-update-badges`（追加前の `0044384`）。
- 最新の観測日付が進んだ場合、または同じ日付の数値が変わった場合にNEWを付ける。文字列の書式だけの変更や古い日付への戻りは対象外。
- 初回表示は比較対象がないためNEWを付けない。表示中は前回の基準を固定し、再取得後も目印を保つ。次にページを開くと今回表示した値が基準になる。
- 比較データはこのブラウザーの `ichi-last-seen-indicators-v1` に保存。他端末とは同期しない。保存拒否や破損した設定で表示を止めない。
- この目印は画面に表示された最新観測値の比較であり、公式の発表時刻や未読記事の判定ではない。
