# スワイプ中心の銘柄切替

> 2026-11-13追記：実機利用でTradingView再生成を伴う切替が重いと分かり、スワイプ中心の操作は撤回。現在は左右ボタンと銘柄一覧を使用する。本書の以下は当時の実装記録として残す。

2026-11-12 JST。ユーザーが直前の操作改善案を採用。15銘柄や取得元を変更する作業ではない。

- 中央に現在の銘柄、左右に前後の銘柄名。指・マウスのドラッグにバーが追従する。
- 左へ動かすと次、右へ動かすと前。通常は48px、素早い操作は24px以上で切替。縦方向優勢の操作は切替せず、pan-yによるネイティブの縦スクロールに任せる。先頭/最後では抵抗を付け、折り返さない。
- 短い操作は元へ戻り、切替時は新しい銘柄名が横から入る。prefers-reduced-motionではアニメーション/戻りのトランジションを無効化。
- 長い15ボタン列は常設せず、上部「銘柄一覧」から開く補助の一覧へ移動。スマホは下部シート、PCは中央ダイアログ。名前のタップによる直接選択とお気に入りフィルターを維持する。
- 左右の銘柄名はクリック/タップも可能。バーへフォーカスして左右キーでも選択できる。選択名はaria-liveで通知する。
- アプリ側のバーだけが動く。TradingView iframeを覆わず、内部ジェスチャーを横取りしない。選択前のドラッグや一覧を開く操作で、次の銘柄のウィジェットを先読みしない。
- 15銘柄の完全シンボル・並び順、Symbol Overview、初期1Y、既存の注目帯・右下スケジュール、保存履歴、ダッシュボード41項目、取得処理・データ・お気に入り保存情報は維持。
