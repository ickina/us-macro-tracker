# 表示名と取得系列の確認事項

2026-11-11。記録のみ。取得系列・計算・表示を変更していない。マーケットUI案とは別の作業とする。

| 現在の表記 | 実際の系列 | 問題と検討対象 |
| --- | --- | --- |
| WTI 原油先物 | DCOILWTICO | Cushing現物価格。系列を維持するなら「WTI原油（Cushing現物）」等への表示名訂正が候補。先物へ無断変更しない |
| 実質国内総生産・前期比年率 | GDPと取得時pca計算 | GDPは名目系列。「実質」を維持するなら系列・履歴・計算の別途検証と承認が必要。GDPC1へ自動置換しない |
| FF金利（政策金利） | FEDFUNDS | 月次平均の実効FF金利。誘導目標そのものとは区別する。日次や目標レンジ系列へ無断変更しない |
| ドルインデックス（名目総合） | DTWEXBGS | 総合貿易加重指数。DXYとは異なる。DXYへの置換をしない |

これらは採用済みマーケット銘柄構成を変更する指示ではない。訂正実装の際は名称と系列のどちらを維持するかを明記する。
